## 六、关键系统设计

### 6.1 多语言 + 多货币（N1 / N4）
- **设计基准语言 = English**。所有 UI 文案以 `en` 为排版基准，组件宽度、字号、留白按英文调好；其他语言只做文本替换，不重新排版。
- 文案以 key 存储（`t('product.addToCart')`），语言包放 `packages/i18n/locales/*.json`。
- 首批语言：`en`（基准）、`zh`、`es`、`fr`、`de`、`pt`、`ja`；`ar` 预留 RTL 支持。
- 语言检测：URL 前缀（`/en/...`）为主 + 首次访问按 `Accept-Language` / IP 推荐，用户可手动切换并写入 cookie。
- 货币：`USD / EUR / GBP / CAD / AUD / JPY / BRL`，按国家推荐默认货币，可手动切换；价格由 USD 按 `ExchangeRate` 换算并做**心理价位取整**（如 17.00 → 16.90 / 17.00 依币种规则）。
- 货币切换只影响展示，结算币种与汇率快照写入订单。

### 6.2 订单与物流（N2）
- 状态机：
  - 支付：`pending → paid / failed / refunded`
  - 履约：`unfulfilled → packing → shipped → in_transit → delivered`（异常 `exception`）
- 前台 `/orders/track`：输入**订单号 + 邮箱**即可查询（免登录）；登录后「我的订单」直接查看。
- 物流轨迹：后台可**批量导入承运商 + 单号**（CSV 粘贴或 Excel）；系统按 `Shipment.events` 展示时间轴。
- 对接预留：`ShippingProvider` 抽象接口，首批用「手工/静态轨迹」，后续接 AfterShip / 17TRACK 自动拉取（接口位置：`packages/shared/src/shipping/`）。
- 发货后自动触发邮件通知（邮件模板在 `packages/i18n`）。

### 6.3 批量导入（N3）— 文件夹式
**目录约定**（`data/imports/`）：
```
data/imports/
└─ 2026-27_Barcelona/                 一个款式/系列 = 一个文件夹
   ├─ products.xlsx  (或 .csv/.json)  产品清单（必需）
   ├─ images/                         按 SKU 分子目录（必需）
   │   ├─ BAR-2627-HOME-FAN/  1.jpg 2.jpg 3.jpg 4.jpg
   │   └─ BAR-2627-AWAY-FAN/  1.jpg ...
   └─ meta.json（可选）               默认分类、标签、版本
```
**清单字段**：`sku, title, season, team, league, type, version, price_usd, compare_price_usd, size_range, stock, description, image_folder`

**导入流程（后台 `/products/import`）**：
1. 拖拽/选择**整个系列文件夹**（或服务端扫描 `data/imports`）
2. 自动解析清单 + 匹配 `images/<sku>/` 图片
3. **字段映射界面**：列名 ↔ 系统字段，可保存为模板
4. **校验预览表**：缺失图片、SKU 重复、价格格式错误、尺码非法 → 逐行标红，不合法行不入
5. 确认后入库，**状态一律 `draft`（未上架）**
6. 导入完成后跳转商品列表，**由你勾选批量上架 / 下架 / 删除**
7. 幂等：同一 `sku` 再次导入为更新，不产生重复商品
8. 每次导入生成 `ImportBatch` 记录，可回滚、可查看日志

> 批量操作：列表支持全选/按筛选结果全选 → 上架、下架、改价、改库存、删除（删除为软删 `archived`，可恢复）。

### 6.4 客户管理 CRM（N9）
**客户档案**：是否注册、国家/货币、来源渠道、首次/末次访问、浏览商品 Top、加购未付款、订单数、**回购次数**、累计金额（LTV）、是否留联系方式（邮箱/WhatsApp/电话）、标签。

**行为事件**（`CustomerEvent`）：
| 事件 | 记录内容 |
|---|---|
| `view_product` | 商品、进入时间、**停留时长**、来源页 |
| `add_to_cart` / `remove_from_cart` | 商品、SKU、数量 |
| `checkout_start` | 金额、是否完成 |
| `order` | 订单号、金额 |
| `contact_submit` | 联系方式类型 |
| `return_visit` | 回访链接点击 |

**回访管理**（`FollowUp`）：
- 状态：`待回访 / 联系中 / 已转化 / 已流失 / 不感兴趣`
- 字段：负责人、下次跟进时间、备注、历史记录（时间线）
- 看板：今日待回访、逾期未跟进、高意向（加购未付款 / 多次浏览）、高价值（回购 ≥ 2）

**常用筛选**：未注册、已留联系方式、加购未付款、近 7 天活跃、回购次数 ≥ N、沉睡 N 天。

### 6.5 支付占位（N8）
- 抽象 `PaymentProvider` 接口（`packages/shared/src/payment/`），当前实现 `PlaceholderProvider`。
- 结算页保留完整 UI：地址表单、配送方式、支付方式选择区、订单摘要。
- 支付方式区域显示「**Online payment coming soon**」，当前走「线下/人工核对」：下单生成 `pending` 订单，后台可手动标记 `paid`。
- 后续接入 Stripe / PayPal 时只替换 Provider 实现，UI 与订单流程不动。

### 6.6 品牌与域名占位（N7）
- 统一在 `packages/shared/src/config/brand.ts`：
  ```ts
  export const BRAND = {
    name: 'BRAND_NAME',        // TODO: 替换品牌名
    domain: 'STORE_DOMAIN',    // TODO: 替换前台域名
    adminDomain: 'ADMIN_DOMAIN',
    logoLight: '/brand/logo-placeholder.svg',
    logoDark: '/brand/logo-placeholder.svg',
    supportEmail: 'support@STORE_DOMAIN',
    whatsapp: '',              // TODO
  }
  ```
- 所有出现 Logo 的位置使用 `<BrandLogo />` 组件，源码内以 `<!-- BRAND LOGO -->` 注释标注，替换时只改一处。
- 后台 `/settings` 提供「品牌信息」表单，可在线改名/换 Logo，无需改代码。

### 6.7 足球鼠标光标（N5）
- 自定义 cursor：SVG 足球（带缝线纹理，不用 emoji），跟随带轻微惯性；滚动时球体旋转。
- 交互态：hover 可点击元素 → 轻微放大 + 高亮描边；点击 → 踢击微动效（位移 8px，300ms）。
- 约束：`prefers-reduced-motion` 与触屏设备自动回退系统光标；全站性能用 `transform` + rAF，不引起重排。
- 设计上属「点缀」，不得干扰阅读（尺寸 24px，不遮挡文字）。

### 6.8 第三方服务：免费方案清单（当前全部使用免费/零成本方案）

> 原则：先零成本跑通，接口位置与 Provider 抽象留好，后续可无痛替换付费服务。

| 能力 | 当前免费方案 | 说明与限制 | 后续可替换 |
|---|---|---|---|
| **翻译** | ① 静态语言包人工维护（主）<br>② `LibreTranslate` 自建/公共实例（辅，免费开源）<br>③ `MyMemory` 免费额度 5000 字/天（兜底） | UI 文案以静态包为准；商品标题等动态内容用 ②③ 预翻译后入库缓存，不实时调用 | DeepL / Google Translate |
| **汇率** | `frankfurter.app`（开源免费、无需 key）或 `exchangerate.host` | 每日同步一次，失败保留上次汇率 | 付费汇率 API |
| **物流查询** | ① 后台手工/CSV 批量导入单号（主）<br>② 前台按承运商生成**官方查询直链**（如 `17track.net`、`parcelsapp.com`、承运商官网）跳转 | 零成本、零对接；轨迹内容为手工维护的时间轴 | AfterShip / 17TRACK API |
| **支付** | `PlaceholderProvider`（占位）+ 人工核对线下收款 | 见 §6.5 | Stripe / PayPal |
| **邮件通知** | 自建 SMTP（如 Gmail SMTP 免费额度、Resend 免费 3000 封/月） | 发货通知、订单确认 | 付费邮件服务 |

| **埋点统计** | 自建 `CustomerEvent` 表 + 后台看板 | 无需第三方 | GA4 / Mixpanel |

## 七、设计规范摘要（完整版见 `docs/设计规范.md`）

| 维度 | 标准 |
|---|---|
| 权重 | 素材质感 70% + 排版尺度 20% + 动效 10% |
