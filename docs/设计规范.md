# 球衣站 UI 设计规范（高级感执行标准）

> 目标：面向国际客户的中高端球衣电商。所有页面按此规范执行。

---

## 一、权重模型：精力该花在哪

| 项 | 权重 | 具体内容 |
|---|---|---|
| 素材质感 | **70%** | 真实商品摄影、统一光源方向、统一裁切比例、极淡阴影、统一背景色 |
| 排版尺度 | 20% | 字号对比、留白比例、字体套数、网格对齐 |
| 动效 | 10% | 慢、少、只做 opacity 与 transform |

**结论**：素材不到位时，任何动效与特效都救不回观感。开工前先解决图片。

---

## 二、素材规范（最高优先级）

- 商品图裁切比例统一 **3:4**，主体占画面 70–80%，居中
- 光源方向统一（左上 45°），背景统一（浅灰 #F2F1EE 或深灰 #141416，全站只用一种）
- 每件商品 ≥ 4 图：正面 / 背面 / 队徽特写 / 上身或平铺细节
- 图片格式 WebP，宽度 800–1200px，压缩后单张 ≤ 150KB
- 允许极淡阴影 `0 20px 40px rgba(0,0,0,.06)`，**禁止发光、描边、强投影**
- 禁止使用网络下载的盗图与带水印图；队徽与赞助商 Logo 需确认授权

---

## 三、排版规范

- 标题 : 正文字号 ≈ **3 : 1**（如 36px / 12px，或 64px / 16px）
- 字重只用 **两档**：400（正文）与 500 或 700（标题），不出现第三档
- 字体最多两套：一套显示字体（无衬线 grotesk，如 Inter / Helvetica Now / Archivo）+ 一套正文（同族或衬线）
- 标题 `letter-spacing: -0.02em ~ -0.04em`；小字标签用大写 + `letter-spacing: .1em~.2em`
- 正文行高 1.6–1.8；英文正文宽度 ≤ 65 字符
- 中英文混排时，英文用显示字体，中文用无衬线黑体，避免同一行两种气质

---

## 四、色彩规范

- 三个色为止：**背景 + 主色（中性）+ 点缀色**
- 背景不用纯黑纯白：深底用 `#0A0A0B`，浅底用 `#F5F3EF`
- 点缀色占比 **< 5%**，只出现在：价格、主按钮、角标
- 商品本身的队色（红蓝黄绿）由图片承担，**不进界面配色**
- 分隔线用 `rgba(255,255,255,.08)` 级别，不用实色粗线

---

## 五、动效规范

| 参数 | 取值 |
|---|---|
| 时长 | 400–800ms |
| 缓动 | `cubic-bezier(.16,1,.3,1)`（ease-out-expo） |
| 位移 | 8–24px |
| 可动属性 | 仅 `opacity` 与 `transform` |
| 数量 | 同一元素一次只动一件事 |

- 滚动入场：淡入 + 上移 16–24px，stagger 间隔 60–80ms
- 卡片悬停：图片 `scale(1.04)`、卡片上移 6px，600ms，不做 3D 翻转、不做发光
- 页面切换：淡入 300ms，不做滑动、不做缩放
- 首屏大图：Ken Burns 极慢缩放（20s 循环，1.0 → 1.06）可用
- 必须支持 `prefers-reduced-motion`

---

## 六、留白与网格

- 内容宽度 1200–1400px，左右边距 ≥ 屏宽 8%
- 首屏元素 **≤ 3 个**（大图 / 标题 / 一个按钮）
- 模块垂直间距 ≥ 一个标题高度（通常 96–140px）
- 商品网格：桌面 4 列，间距 24–32px；移动 2 列，间距 12px

---

## 七、廉价感黑名单（禁止出现）

1. 渐变填充文字
2. 霓虹发光、外发光、box-shadow 光晕
3. 粒子爆炸、烟花、纸屑雨
4. 故障字 glitch、扫描线、闪烁
5. 闪白冲击、画面抖动
6. 过大的圆角（> 16px）+ 厚重阴影叠加
7. 用 emoji 当功能图标
8. 纯黑 `#000` 或纯白 `#fff` 作背景
9. 一屏内出现 4 种以上颜色
10. 动效时长 < 200ms 或 > 1.2s

---

## 八、页面执行清单

**首页**
- [ ] 首屏：一张大图 + 一句 6 词以内标题 + 一个按钮，其余全部下移
- [ ] 分类入口用纯文字或小图，不用彩色色块按钮
- [ ] 商品区只放 8–12 件，宁少勿多

**分类页**
- [ ] 筛选器放左侧或顶部，样式极简（下划线/小字），不用彩色胶囊堆砌
- [ ] 卡片信息三层：图 / 队名+版本 / 价格（原价灰色划掉）

**商品详情页**
- [ ] 左侧大图占 55–60% 宽度，右侧信息区留白充足
- [ ] 尺码用方形描边块，选中态只改边框与背景，不做缩放动画
- [ ] 信任元素（全球配送 / 30 天退换 / 支付方式图标）放在价格下方与页脚

**页脚**
- [ ] 必须有：配送时效、退换政策、支付方式图标、联系方式
