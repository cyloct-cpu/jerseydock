# 球衣跨境电商网站 — 详细方案

> 面向国际客户销售各国 / 各联赛球衣，含炫酷 UI 动效前台 + 管理后台。
> 分类与商品结构参考 chenyikan.shop（Shoplazza 店匠建站）。

---

## 一、参考站分析结论（chenyikan.shop）

**平台**：Shoplazza（店匠）建站，暴露标准商品 JSON 接口（`/products.json`、`/collections/{slug}/products.json`），便于结构化采集。

**导航分类体系**（与我们截图中的导航一致）：
- 赛季：2026-27 赛季、2025-26 赛季
- 复古（Retro）
- 国家队：阿根廷、墨西哥、荷兰、英格兰、日本、葡萄牙、意大利、法国、德国、巴西、西班牙、威尔士
- 俱乐部：巴黎、皇马、拜仁、巴萨、阿森纳、尤文、曼联、曼城、利物浦、切尔西、国米、AC米兰
- 品类：儿童尺码、秋冬系列、风衣、短裤

**商品属性结构**：
- 标题（如 `2026-27 Barcelona Home Jersey - Fan Edition`）
- 价格：现价 / 原价 / 折扣额，多级满减（Buy 3 -$5 / Buy 8 -$10 / Buy 10 -$18）
- 尺码变体：S / M / L / XL / 2XL / 3XL / 4XL
- 版本：球迷版（Fan Edition）/ 球员版（Player Version）
- 销量、预计送达时间、图文描述

## 二、技术栈选型

### 前台（核心：炫酷动效）
| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | **Next.js 15（App Router）+ React 19 + TypeScript** | SSR/SSG 利于 SEO 与全球访问速度，国际电商标配 |
| 样式 | **Tailwind CSS 4** | 快速构建定制化视觉，暗色运动风 |
| UI 组件库 | **shadcn/ui**（前台，可深度定制）+ **Radix UI** 无障碍基座 | 组件代码归项目所有，自由定制炫酷样式，不受组件库默认风格束缚 |
| 动效库 | **GSAP + ScrollTrigger**（首页滚动叙事、视差、数字滚动） | 电商炫酷首选，性能强 |
| | **Framer Motion**（页面过渡、卡片悬停、购物车抽屉） | 声明式、与 React 深度集成 |
| | **Lenis**（平滑滚动） | 高端质感 |
| | **Swiper**（商品图/集合轮播） | 移动端体验好 |
| 备选增强 | react-three-fiber（球衣 3D 展示）、Lottie（微交互） | 二期可选 |

### 后台管理
- 同一 Next.js 项目的 `/admin` 路由段，独立布局与鉴权
- UI：**shadcn/ui + TanStack Table**（表格）+ **React Hook Form + Zod**（表单校验）
- 图表：**Recharts** 数据看板

### 后端与数据
- 数据库：**PostgreSQL**（推荐配套云服务托管；开发期可先 SQLite/本地 PG）
- ORM：**Prisma** 或 **Drizzle**
- 图片：本地起步，正式上线迁移云存储 + CDN
- 认证：后台管理员用邮箱密码 + NextAuth；前台买家可游客结算 + 可选注册

### 国际化（针对海外客户）
- 语言：英文为默认（i18n 预留多语言扩展，next-intl）
- 币种：EUR / USD / GBP 展示，结算币种统一，前端按汇率换算
- 支付：**Stripe**（卡）+ **PayPal**；预留 Klarna 等分期
- 物流：展示各国预计送达时间（参考站同款逻辑）

## 三、数据模型（核心表）

```
Category    id, name, slug, type(national_team|club|season|retro|kids|outerwear|shorts...), parent_id, image
Product     id, title, slug, description, base_price, compare_price, currency,
            season, team_id, league, type(home|away|third|goalkeeper|training|retro),
            version(fan|player), images[], sold_count, is_active
Variant     id, product_id, size(S..4XL), sku, stock, price_adjustment
Collection  产品集合（对应前台各分类页），与 Product 多对多
Order       id, email, items[], subtotal, discount, shipping, total, currency,
            payment_status, fulfillment_status, address, tracking_no
Promotion   满减规则（满3减5 / 满8减10 / 满10减18），可配置
AdminUser   管理员账号、角色
```

## 四、商品数据采集方案

1. **接口探测**：Shoplazza 标准接口 `https://www.chenyikan.shop/products.json?limit=250&page=N` 及各 collection 的 products.json，可拿到标题、价格、图片、变体、分类全量数据。
2. **采集脚本**（Python + requests）：遍历 sitemap/collection 列表 → 拉取分页 JSON → 规整为本站数据模型 → 输出 `products.json`。
3. **图片处理**：下载原图 → 按商品 slug 归档 → 上传自有图床/云存储，替换 URL。
4. **批量导入**：管理后台提供「JSON 批量导入」功能，一键入库，后续人工补库存/价格。
5. ⚠️ **合规提示**：参考站的商品图片、俱乐部队徽、赞助商 Logo 存在版权风险。采集数据建议先用于**开发测试与占位**；正式对外销售前，应替换为自有拍摄/授权素材，并确认目标市场的知识产权合规（仿版球衣本身在欧美市场也有法律风险，需自行评估）。

## 五、前台页面与动效规划

| 页面 | 内容 | 动效亮点 |
|---|---|---|
| 首页 | Hero 大屏（赛季主推）、国家队/俱乐部集合入口、Retro 专区、爆款推荐 | GSAP 滚动视差 + 大字标题逐行入场 + 商品卡 3D 悬停倾斜 + 跑马灯公告栏 |
| 分类/集合页 | 网格商品列表、筛选（联赛/尺码/版本/价格排序） | 卡片瀑布式入场（stagger）、骨架屏、无限滚动 |
| 商品详情 | 图廊、尺码/版本选择、满减提示、配送预估 | 图廊视差缩放、加购飞入动画、尺码切换微动效 |
| 购物车/结算 | 抽屉购物车、多币种结算 | 抽屉弹性滑出、数量变更数字滚动 |
| 静态页 | About / Shipping / Returns / FAQ | 简洁入场动效 |

**视觉风格**：暗色球场夜赛氛围（深底 + 荧光绿/电光色点缀），大号运动字体（Archivo/Space Grotesk 类），贴布刺绣质感细节。

## 六、管理后台功能清单

1. **数据看板**：销售额、订单量、热销商品、近 30 天趋势图
2. **商品管理**：列表/搜索/筛选、新建/编辑、多图上传、变体（尺码×版本）与库存、上下架
3. **批量导入**：上传采集 JSON，映射字段后入库；图片 URL 批量替换
4. **分类管理**：树形分类（国家队/俱乐部/赛季/品类），拖拽排序
5. **订单管理**：列表、详情、发货（填单号）、退款标记
6. **促销管理**：满减规则配置、折扣码
7. **管理员**：账号、角色权限（超管/运营只读）

## 七、实施步骤（六个阶段）

| 阶段 | 内容 | 产出 |
|---|---|---|
| P1 基建 | Next.js 项目初始化、Tailwind + shadcn/ui、数据库与 Prisma 模型 | 可运行骨架 |
| P2 采集 | 探测参考站接口、写爬虫脚本、下载图片、导出 JSON | 全量商品数据 |
| P3 前台核心 | 首页、分类页、详情页、购物车（含全部动效） | 可浏览可加购 |
| P4 后台 | /admin 全部模块 + 鉴权 + 批量导入 | 管理闭环 |
| P5 交易 | Stripe/PayPal 测试模式结算、订单落库、邮件通知 | 完整下单流程 |
| P6 上线 | 多币种/SEO/性能优化、部署发布 | 正式可访问 |

> 建议先本地跑通 P1–P5（用测试数据与测试支付），确认效果后再接真实域名与正式支付账号。

## 八、待你确认的决策点

1. **域名/品牌名**（影响 SEO 与 Logo 设计）
2. **支付渠道**：Stripe + PayPal 是否可开通（需海外主体或 Stripe 支持的地区主体）
3. **图片版权策略**：先用采集图占位上线测试，还是直接准备自有素材
4. **起步范围**：先做全部分类，还是先聚焦「国家队 + 五大联赛俱乐部」核心 SKU
